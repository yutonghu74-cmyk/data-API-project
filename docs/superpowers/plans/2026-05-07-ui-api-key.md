# UI 配置 API Key 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让用户只需在 admin.html 管理员面板中添加 Anthropic 配置即可使用聊天功能，无需配置 .env 文件。

**Architecture:** server.py 启动时 ANTHROPIC_API_KEY 改为可选（仅警告不退出），新增 GET /active-config 端点返回激活的 anthropic 配置 ID；/chat 请求时从数据库动态读取 api_key 创建临时 Anthropic 客户端。claude.html 页面加载时调用 /active-config 获取 config_id，发送消息时自动带上。

**Tech Stack:** Python FastAPI + sqlite3，原生 ES Modules

- [ ] **Step 2: 新增 get_active_anthropic_key() 函数**

在上面代码之后（`app = FastAPI()` 之前）插入：

```python
def get_active_anthropic_key() -> str | None:
    """从 api_configs 表读取 provider=anthropic 且 is_active=1 的第一条密钥。"""
    try:
        with get_db() as conn:
            row = conn.execute(
                "SELECT api_key FROM api_configs WHERE provider='anthropic' AND is_active=1 ORDER BY id DESC LIMIT 1"
            ).fetchone()
        return row["api_key"] if row else None
    except Exception:
        return None
```

- [ ] **Step 3: 新增 GET /active-config 端点**

在 `@app.get("/models")` 端点之后插入：

```python
@app.get("/active-config")
def active_config():
    """返回当前激活的 anthropic 配置 ID，供前端带入 /chat 请求以记录统计。"""
    try:
        with get_db() as conn:
            row = conn.execute(
                "SELECT id FROM api_configs WHERE provider='anthropic' AND is_active=1 ORDER BY id DESC LIMIT 1"
            ).fetchone()
        return {"config_id": row["id"] if row else None}
    except Exception:
        return {"config_id": None}
```

- [ ] **Step 4: 替换 /chat 端点中的客户端创建逻辑**

找到 `@app.post("/chat")` 端点内 `generate()` 函数中的：
```python

```

将整个 `generate()` 函数中的 `client` 引用改为动态获取。具体：在 `generate()` 函数开头（`input_tokens = 0` 之前）插入：

```python
        # 动态获取 API Key：优先用数据库中的激活配置，fallback 到环境变量
        _key = get_active_anthropic_key() or _env_api_key
        if not _key:

            yield f"data: {json.dumps({'error': error_msg})}\n\n"
            return
        _client = anthropic.Anthropic(api_key=_key)
```

并将 `with client.messages.stream(**kwargs) as stream:` 改为：
```python
            with _client.messages.stream(**kwargs) as stream:
```

### Task 2: claude.html — 页面加载时获取 active config_id

**Files:**

- [ ] **Step 1: 在 stream.js 的 fetchModels 之后，新增 fetchActiveConfig 调用**

在 claude.html 的 `<script type="module">` 中，找到：
```js
    let history = [];
```

```js
    let activeConfigId = null;

    // 获取激活的 anthropic 配置 ID，用于统计埋点

      .then(r => r.json())
```
