# 数据平台 · 使用文档

> 面向**普通使用者**的操作手册(不含开发细节)。如需启动/部署相关内容,见 `CLAUDE.md`。

---

## 一、平台简介

第三方 API 调用平台,统一管理 Anthropic / OpenAI / Gemini 等多家供应商的 Key,提供:
- **在线对话**(类 ChatGPT 界面)
- **批量数据处理**(用 Excel/CSV/JSON/Parquet 喂数据,跑 AI 后导出)
- **API 申请 → 审核 → 分配** 三层流程
- **使用统计 / 计费监控**

---

## 二、启动方式

### 启动后端服务(管理员)

```bash
cd /path/to/api-web-project
pip install -r requirements.txt
python server.py        # 自动热重载,监听 127.0.0.1:8000
```

### 普通用户访问

浏览器打开 `pages/login.html`(或站点首页),登录后进入。

## 三、首次登录

1. 注册账号(或由管理员开账号)

## 四、模块详解

### 4.1 API调用

包含两个 sub-tab:**在线使用** / **批量处理**。

#### 在线使用(类 ChatGPT)

- 顶部选 **供应商 / API名称 / 模型**
- 中间消息流,左侧历史会话列表(可拖宽度)
- 输入框右下角:
  - 📎 **附件**:上传图片/PDF/Markdown/CSV,首次点击会弹"确认上传数据不属于公司保密资产",同会话内不再问
  - **发送**(Enter 发送,Shift+Enter 换行)
- 上方红色横幅常驻提醒"勿提交保密资产"

#### 批量处理(三个 Tab)

**1️⃣ 前端配置(零代码)** — 左右双栏

左侧表单:

1. **任务名称**(留空自动用 `日期_NA`)
2. **数据来源** — 两种模式:
   - 📂 上传文件:CSV / Excel / JSON / **Parquet**(parquet 由服务器解析)
   - 📊 已有数据集:选平台预置数据集
3. **选择字段**:点击 chip 多选要作为 AI 输入的列
4. **API 配置**:供应商 → API名称 → 模型 三级联动
5. **Prompt 模板**:用 `{字段名}` 引用,例:`请分析以下评论:{评论内容}`
6. **开始批跑**

右侧两个 Tab:

- **运行日志**:实时进度条 + 每行 `[行N] ✓/✗ 输出/错误`
- **结果文件**:成功后表格预览,可导出 CSV

**2️⃣ 脚本配置(高级)**

- Monaco 编辑器写 Python,直接调 `chat(prompt)`、`save_file(path)`、`show_image(path)` 等内置函数
- 上传数据文件后,变量 `df` 自动持有 DataFrame
- 运行后右侧显示 stdout 日志 + 结果文件列表(可打包下载)

**3️⃣ 任务列表(历史)**

- 表头全部支持**排序 + 过滤**(下拉/模糊):任务ID / 任务名称 / 来源 / 模型 / 状态 / 进度 / 创建时间
- 每行操作:**配置**(回填到对应 Tab,自动调出历史运行日志) / **结果**(进详情看每行结果) / **续跑** / **重跑** / **下载**
- 任务运行中自动 3s 刷新

---

### 4.2 API管理(申请/审核)

三个 Tab:

**API申请** — 我的申请记录

- 列:供应商 / API名称 / 审批人 / 需求项目 / 负责人 / 申请额度 / 状态(审核中/已通过/已拒绝) / 申请时间 / 审核意见
- 表头支持下拉过滤(供应商、审批人、状态) + 模糊筛选(项目名、负责人等)
- 右上角「+ 新增申请」:选审批人 → 选供应商 → 填项目/详情/预算/负责人/抄送人 → 提交

**API审核** — 待审核列表(所有登录用户可见,只有指定审批人能操作)

- 看到所有人的申请
- 自己作为审批人的 pending 单子,按钮高亮可点
- 审核时分配具体 API key、写审核意见、通过/拒绝

**密钥管理** — iframe 内嵌 `keys.html`(仅管理员真正能操作)

### 4.3 使用统计

**个人看板**(所有用户可见):

- 今日核心指标 / 我的 API key 余额

**平台看板**(仅管理员)— 时间维度按钮:**今天 / 7天 / 30天 / 90天 / 总量**(联动以下所有图表):

| 分区 | 内容 |
|---|---|
| 核心指标 | 请求量 / Token / 成本 / **活跃项目**(含项目名列表,悬浮看完整) / 活跃用户 / 成功率 / 平均响应 |
| 平台趋势 | 请求量曲线 / 成本曲线 / **模型使用趋势 Top5**(可点「展开 ▾」看 Top10) |
| 调用排行 | 项目 Top10 / 用户 Top10(都可「展开 ▾」看全量) |
| 模型治理 | 模型 / 请求量 / Token / 成本 / 成功率 / 平均延迟(可「展开 ▾」看全量) |
| 异常监控 | 失败率 / 失败数 / 超时数 / 日同比 + 最近 10 条失败明细 |

### 4.4 密钥管理(仅管理员)

三层结构表:**供应商 → 子帐号 → API key**

- 表头每列「⌄」按钮:点开下拉(供应商/子帐号/管理员/创建人)或模糊输入框过滤
- **+ 新增供应商**:配置 provider / Base URL / 后端网址 / 费用接口路径(可选,用于自动拉余额)
- **+ 新增 API key** Modal C:
  - 选所属供应商
  - 输入子帐号名(选已有或新建)
  - API名称 + API key
  - **批量导入**:点「选择 Excel 文件」上传 (`api_keys_template.xlsx` 为模板),自动导入 + 显示「成功 N 条 / 重复跳过 N 条 / 失败 N 条」
  - 指定管理员(必填)
- 行内操作:**编辑**(走 Modal D 统一编辑界面) / **删除**(已被调用的 key 不可删,防破坏审计链)

普通用户也能进入这个页面,但只看不能改;能编辑/删除**自己创建**的 key。

---

### 4.5 用户管理(仅管理员)

- 列出全部用户(用户名 / 角色 / 注册时间)
- 操作:**切换角色** / **重置密码** / **删除用户**(自己的账号不可删,不可改自己角色)

## 五、常见问题

**Q: 上传文件第一次会弹"请确认上传数据不属于公司保密资产"?**
A: 是,刷新页面后第一次点 📎 / 选文件会问一次,确认后同会话内不再弹。

**Q: 批量处理第一次进很慢?**
A: 解析 Excel 的 xlsx.js 库(≈944KB)按需懒加载,**纯 CSV/JSON/Parquet 路径不会触发**;CSV/JSON 文件首屏更快。

**Q: parquet 文件预览不出来?**
A: parquet 由服务器解析(浏览器原生不支持),所以本地不显示预览表,只会用服务器返回的列名让你选字段。

**Q: 看不到「密钥管理」/「用户管理」入口?**
A: 你不是管理员。问平台管理员升级你的角色,或确认登录账号正确。

**Q: 数据库在哪?备份怎么做?**
A: `项目根目录/admin.db` (SQLite)。重要操作前: `cp admin.db admin.db.backup-$(date +%Y%m%d-%H%M%S)`。

**Q: 改了 Python 代码需要重启吗?**
A: 不用,已开 `--reload`,保存 .py 后 1-2 秒自动重启。前端 HTML/JS 改完浏览器硬刷新(`Cmd+Shift+R`)。
